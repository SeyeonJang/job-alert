# job-alert

회사 채용 페이지에 새 공고가 올라오면 디스코드로 알려주는 봇.
GitHub Actions가 하루 4번(한국 시간 08:50, 12:50, 17:50, 21:50) 돌아간다.

## 하는 일

1. 구글 시트에서 회사 목록(회사명, 채용 페이지)을 읽는다.
2. 회사마다 채용 페이지의 공고 목록을 가져온다.
3. 아래 조건에 맞는 공고만 디스코드로 보낸다. 한 번 보낸 공고는 다시 안 보낸다.
   - **직무**: 서비스 기획 · PM/PO · 데이터 분석 · 전략/문제해결형. 애매하면 `❔직무 확인`을 붙여서 보낸다.
   - **고용형태**: 정규직, 인턴만. 계약직·어시스턴트·아르바이트는 뺀다.
   - **경력**: 신입, 경력 무관, 경력 1년 이하만. 연차가 목록에 없으면 상세 페이지의 자격요건을 읽는다(우대사항 연차는 무시).
4. 사이트를 못 읽으면 디스코드로 `⚠️` 경고를 한 번 보낸다.

## 회사 추가하기

시트에 행만 추가하면 다음 실행부터 반영된다. 잠깐 끄고 싶으면 `사용` 열을 만들어 `X`를 적는다.

| 회사명 | 채용 페이지 | 사용 |
|---|---|---|
| 당근 | https://careers.daangn.com/jobs/ | |

그리팅·Greenhouse·네이버 채용 시스템 등은 링크만 넣으면 자동으로 인식한다.
처음 보는 구조면 디스코드로 "자동 인식 실패"가 오는데, 그 회사는 수집기를 따로 추가해야 한다.

## 설정

레포 Settings → Secrets and variables → Actions 에 두 값이 있어야 한다.

- `DISCORD_WEBHOOK_URL` — 디스코드 웹후크 주소
- `SHEET_CSV_URL` — 회사 목록 구글 시트 링크 (링크가 있는 사람은 볼 수 있게 공유)

## 고치기

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 직무·고용형태 키워드, 허용 연차 | `jobalert/rules.py` |
| 실행 시간 | `.github/workflows/alert.yml` 의 `cron` (UTC 기준) |
| 메시지 모양 | `jobalert/notify.py` |
| 사이트별 수집 방법 | `jobalert/adapters/` |

Actions 탭 → 채용 알림 → Run workflow 로 바로 실행할 수 있다. `dry_run`을 켜면 디스코드로 보내지 않고 결과 요약만 남긴다.
보낸 공고 기록은 `state/seen.json` 에 쌓인다.
